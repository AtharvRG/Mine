# Branching Analysis: Task R10b (Stop during streaming null check before persisting [Interrupted] to raw_message)

Date: 2026-11-04  
Status: In Progress  
Authors: Antigravity  

---

### 1. Guarantee Restatement
- **Guarantee 1 (`extractReplyFromJsonStream` null return)**: `extractReplyFromJsonStream` must return `null` whenever a real user-facing reply text has not yet started streaming. If the stream contains JSON envelope structure, thought/preamble, or tool calls before `"reply":"`, or if `"reply":""` is empty, it returns `null`. It must NEVER return `"Thinking..."`.
- **Guarantee 2 (No bogus messages in `raw_message`)**: When a stream is stopped or cancelled during the preamble/thinking/tool-call phase (before any real reply text is output), no assistant message or `[Interrupted]` message must be persisted to the append-only `raw_message` table.
- **Guarantee 3 (Interrupted real text preserved)**: If real user-facing reply text has begun streaming (e.g. `{"reply":"Hello, here is...`), and the user clicks Stop or the stream cancels, `[Interrupted]` must be appended to the partial real text and persisted to `raw_message` via `storage.insertRawMessage`.
- **Guarantee 4 (Clean UI state cleanup)**: If cancellation occurs before real text begins streaming, the temporary assistant message placeholder in `UiState.chatMessages` must be dropped, leaving no phantom empty bubble.

### 3. Architecture & Fix

1. Update `extractReplyFromJsonStream(jsonStream: String): String?` (internal):
   - Locate `replyMarker = "\"reply\":\""`.
   - If `start == -1`:
     - If `jsonStream.trim().startsWith("{")` -> return `null`.
     - If `!jsonStream.trim().startsWith("{")`: if `jsonStream.isBlank()` -> return `null`; else return `jsonStream`.
   - If `start != -1`:
     - Extract text up to unescaped closing quote (or end of stream if unterminated).
     - Unescape `\\\"` and `\\n`.
     - If unescaped string is empty -> return `null`.
     - Else return unescaped string.
2. In `ChatController.kt` streaming loop:
   ```kotlin
   val display = extractReplyFromJsonStream(currentText)
   if (display != null) {
       updateLastMessage(botId, display)
   }
   ```
3. In `ChatController.kt` cancellation handling:
   ```kotlin
   if (e is CancellationException) {
       withContext(NonCancellable) {
           val msgs = _state.value.chatMessages
           val last = msgs.lastOrNull()
           if (last?.role == "assistant" && !last.content.isNullOrBlank() && last.content != "Thinking...") {
               val intContent = last.content + " [Interrupted]"
               updateLastMessage(last.id, intContent)
               storage.insertRawMessage(last.id, "assistant", intContent)
           } else if (last?.role == "assistant") {
               _state.update { it.copy(chatMessages = it.chatMessages.dropLast(1)) }
           }
       }
       throw e
   }
   ```
