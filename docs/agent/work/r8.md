## 1. Goal and Invariant

### Goal
Fully wire Home Quote Slots per Decisions D-108 and D-109:
1. Slot boundaries:
   - `MORNING` (05:00 - 11:59)
   - `AFTERNOON` (12:00 - 16:59)
   - `EVENING` (17:00 - 20:59)
   - `NIGHT` (21:00 - 04:59)
2. Advance preparation fires 1 hour before each boundary:
   - 04:00 (-> `MORNING`)
   - 11:00 (-> `AFTERNOON`)
   - 16:00 (-> `EVENING`)
   - 20:00 (-> `NIGHT`)
3. Regeneration rule:
   - First live quote generation has `regenCount = 0`.
   - Regenerations increment `regenCount` up to a max of 2 regenerations (at most 3 live generations total per slot).
   - A regeneration is only permitted if `state_hash` has changed.
   - `state_hash` is a deterministic hash of COUNTS only (`open`, `overdue`, `completed-today`, `at-risk flag`); never titles or content.
4. Privacy-safe prompt:
   - Prompt uses counts only: no node titles, no soul facts, no local_only data, no health data.
5. UI State & Lifecycle:
   - `UiState.homeQuote` exposed.
   - `QuoteManager.onHomeOpened()` is the single idempotent entry point: shows stored preset instantly, swaps to live quote upon background completion.
6. Execution & Singletons:
   - Lift `RateLimiter` and `ProviderOrchestrator` to `MineApp` so chat and quote share rate-limiting singletons.
   - Setting `prepare_next_quote_early` (default true) checked before early background preparation.
   - Fallback inexact `AlarmManager` receiver for background preparation without adding unauthorized external dependencies.
   - `CancellationException` is always rethrown and never swallowed.
   - `PresetQuotes`: fix `abs(Int.MIN_VALUE)` bug using `Math.floorMod`.

### Invariant
1. LLM proposes, code decides: Quote selection/regeneration is strictly controlled by deterministic code rules and state hash.
2. Privacy: Zero titles, soul facts, or message content enter quote generation requests.
3. Resilience: Offline/missing provider keeps stored preset; UI never flashes blank or blocks on LLM responses.
4. Cancellation: Coroutine cancellation cleanly propagates without being swallowed by general exception catches.
5. Idempotency: Repeated `onHomeOpened` calls do not trigger duplicate network requests when state hash is unchanged.

## 3. Angles (Mandatory one-line checks)

- **schema and migration**: `quote_slot` table already exists in DB v5 (`slot`, `day_key`, `text`, `generated_at`, `state_hash`, `source`, `regen_count`). No DDL migration needed.
- **concurrency, cancellation, process death, reboot, Doze**: `generateLiveQuote` rethrows `CancellationException`. Quote state is persisted to SQLite so process death preserves quotes. Inexact alarm wakes device or catches up on next maintenance window.
- **failure paths (network, 429, 5xx, malformed output, null args)**: Stream errors or missing API keys retain stored preset gracefully.
- **what a REAL model would send**: Raw text may contain surrounding quotes or multiple lines; sanitize by trimming quotes and taking first non-blank line.
- **user-visible behaviour**: Instant preset quote rendered on Home screen; seamlessly swaps to live quote once generated without layout shift.
- **privacy and security**: Prompt is constructed strictly from numeric counts and slot name; zero node titles, notes, or soul facts.
- **testability**: Unit tests in `QuoteManagerTest` with mock clock and fake transport assert boundary times, hash change requirement, counts-only request payload, and cancellation.
- **battery and performance**: Max 2 regenerations per slot caps LLM generation; background preparation is inexact and infrequent (4 times/day).
- **blast radius**: Re-use of `ProviderOrchestrator` singleton in `MineApp` prevents conflicting network queues between chat and quote generation.

## 4. Pre-mortem: 3 Potential Bugs & Mitigation

1. **Bug**: `Int.MIN_VALUE` in `PresetQuotes.hashCode()` causes `abs(Int.MIN_VALUE)` to remain negative, causing `ArrayIndexOutOfBoundsException`.  
   *Mitigation*: Replace `abs(hash) % pool.size` with `Math.floorMod(hash, pool.size)`.
2. **Bug**: In-flight `generateLiveQuote` job cancels when user rapidly navigates away, but exception is swallowed, leaving state inconsistent.  
   *Mitigation*: Explicitly rethrow `CancellationException` and guard background job updates.
3. **Bug**: Day boundary transition at midnight or slot change leaves old slot quote in `homeQuote`.  
   *Mitigation*: `onHomeOpened` dynamically checks current clock time against `getSlot(now)` and fetches or seeds the correct slot quote.
